# Glossary

English words used in this course, with a short meaning in Bahasa Indonesia.

| Word | Meaning |
|---|---|
| variable | Label untuk menyimpan nilai, seperti label di rak gudang |
| print | Perintah untuk menampilkan sesuatu di layar |
| string (str) | Teks, misalnya nama produk |
| integer (int) | Bilangan bulat |
| float | Bilangan dengan desimal |
| f-string | Teks dengan "lubang" yang diisi nilai variabel |
| list | Daftar nilai, seperti satu kolom Excel |
| index | Nomor urut item di list, mulai dari 0 |
| dictionary (dict) | Kartu dengan nama field dan nilainya |
| key | Nama field di dictionary |
| loop | Pengulangan, seperti drag formula ke bawah |
| function | Aturan buatan sendiri yang bisa dipakai berulang |
| return | Mengembalikan jawaban dari function |
| traceback | Daftar langkah sebelum error, dibaca dari bawah |
| pandas | Tools untuk bekerja dengan tabel di Python |
| DataFrame | Tabel di pandas, seperti satu sheet Excel |
| CSV | File teks berisi tabel, dipisah koma |
| NaN | Sel kosong |
| filter | Mengambil hanya baris yang cocok |
| groupby | Mengelompokkan lalu menjumlahkan, seperti PivotTable |
| merge | Menggabungkan dua tabel lewat kunci, seperti VLOOKUP |
| ABC analysis | Membagi produk menjadi A, B, C menurut kontribusi revenue |
| notebook | Dokumen berisi sel teks dan sel kode |
| repository | Folder proyek di GitHub |
| README | Halaman depan repository |
| commit | Menyimpan satu versi di GitHub dengan catatan |
