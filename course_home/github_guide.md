# GitHub guide

GitHub is a website where you keep your project and show it to others. You click every button yourself.

## At home (after Session 8)
1. Go to github.com and choose **Sign up**. Make an account with your own email.
2. Click **New repository**. Give it a short name, for example `supply-chain-sales-project`.
3. Choose **Public**. This is fine: the data is public and your project has no personal data.
4. Click **Create repository**. Leave it empty for now.

## In Session 9
1. In Colab, choose **File > Save a copy in GitHub**. Pick your repository and save.
2. On github.com open your repository. Click **Add file > Create new file** and name it `README.md`.
3. Write the README (question, data credit, finding, how to run) and click **Commit changes**.
4. Open your repository link in a private browser window. If you can see it, it works.
