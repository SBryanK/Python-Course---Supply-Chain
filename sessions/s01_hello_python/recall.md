# Session 1: daily recall

Three short questions a day. Answer from memory first, then check the answers at the end.

## Tue 17 Nov

1. What does `print()` do, and what does Python show if you do not use it?
2. What is the difference between `6` and `"6"`?
3. Why do we write `round(sales_value, 2)` before showing money?

## Answers

**Tue 17 Nov**
1. It shows a value on the screen. Python shows nothing unless you ask.
2. `6` is a number. `"6"` is text, and Python will not add it to a number.
3. Some decimals are stored a little inexactly, like 15.299999999999999. Rounding shows 15.3.
